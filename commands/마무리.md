# /마무리 — 세션 증류 저장 (컴팩트 대신)

지금 이 세션의 맥락을 **가벼운 세션 노트 1장**으로 증류해 저장한다. 너는 이미 전체 맥락을 들고 있으므로, **추가로 파일을 읽지 말고**(특히 raw 원본을 다시 읽지 말 것 — 토큰 낭비) 머릿속 맥락만으로 작성한다.

## 할 일

1. **작업폴더 확인** — 현재 작업 디렉터리(cwd) 기준. 노트는 `<cwd>\sessions\raw\` 에, 포인터는 `<cwd>\sessions\LATEST.md` 에 저장한다. 폴더가 없으면 만든다.

2. **세션 노트 작성** — 아래 형식으로 **간결하게**(전체 200~400단어 목표, 장황 금지) 작성한다:

   ```markdown
   ---
   date: <YYYY-MM-DD HH:MM>
   project: <cwd의 마지막 폴더명>
   type: session-note
   tags: [session, <주제 태그 1~3개>]
   ---

   # <이번 세션 한 줄 제목>

   ## 한 일
   - <이번 세션에서 실제로 한 작업 핵심만 불릿>

   ## 현재 상태
   - <지금 어디까지 됐는지 / 무엇이 동작·검증됐는지 / 미해결 이슈>

   ## 다음 할 일
   - <다음 세션이 이어서 해야 할 구체적 액션>

   ## 관련
   - [[관련 과거 노트 제목]]  ← sessions\raw\ 에 관련 요약 노트가 있으면 위키링크로 연결, 없으면 생략
   ```

3. **두 곳에 저장**:
   - `<cwd>\sessions\raw\<YYYY_MM_DD__HH.MM>_<짧은제목>.md` — 타임스탬프 노트(누적)
   - `<cwd>\sessions\LATEST.md` — **같은 내용을 덮어쓰기**(새 세션 SessionStart 훅이 이걸 읽어 주입함)

4. **raw는 손대지 않는다** — 대화 원본(.jsonl)은 종료 시 SessionEnd 훅이 자동으로 `sessions\raw\`에 저장한다. 여기서 복사하지 말 것.

5. **마지막 안내** — 저장 끝나면 사용자에게 정확히 이렇게 알린다:
   > ✅ 저장+증류 완료 (`sessions\LATEST.md` 갱신). 이어서 작업 안 할 거면 **`/exit`** 로 나가세요 — 래퍼(cloop)가 새 세션으로 자동 재접속하고, 그때 이 요약이 자동 주입됩니다.

## 주의
- 거짓 요약 금지 — 실제로 한 것만. 안 끝난 건 "미완료"로 적는다.
- 노트는 **가볍게**. 전체 대화를 복붙하지 말 것. 핵심 결정·상태·다음 액션만.
- 옵신 정식 위키화는 나중에 일괄(ADOPT)로 한다 — 지금은 가벼운 노트까지만.
