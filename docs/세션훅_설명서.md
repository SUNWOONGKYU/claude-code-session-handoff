# 세션 핸드오프 설명서 — SessionStart · SessionEnd

> 컴팩트 대신 **`/exit` 한 번**으로: 원본 저장 + 이어가기 요약 + 위키 + 인덱스를 자동 생성하고,
> 새 세션 시작 시 그걸 자동으로 읽어 가볍게 이어가는 시스템.
> 근거: code.claude.com/docs/en/hooks.md · 최종 갱신 2026-06-26

---

## 0. 한눈 흐름 (명령은 `/exit` 하나)

```
[컨텍스트 무거워짐]
   │  /exit            (Ctrl+D 대체 / cloop이면 자동 반복)
   ▼  SessionEnd (자동)
   ├─ session-save-raw.js   → 원본 대화(.jsonl)  → sessions/raw/
   └─ session-to-wiki.js    → 백그라운드 wiki-distill-worker.js (Sonnet 1회):
         · 이어가기 요약  → sessions/summary/  (누적)
         · 위키 노트      → sessions/wiki/      (누적, [[링크]])
         · INDEX.md       → sessions/wiki/INDEX.md (한 줄 설명 갱신)
   │  cloop 자동 재접속
   ▼  SessionStart (자동)
   └─ session-restore.js → 새 세션에 주입:
         ① 최신 이어가기 요약(전체)  ② 직전 위키 노트 본문(전체)  ③ INDEX.md(전체)
   ▼
[가볍게 이어서 작업]
```

핵심: **컨텍스트는 항상 가볍게, 기억은 전부 파일로 영구 보존, 새 출발은 요약+위키+인덱스만 읽음.**

## 0-1. 폴더 구조 (`<작업폴더>/sessions/`)
```
raw/      ← 원본 대화 .jsonl (누적)
summary/  ← 이어가기 요약 (누적 — 매 세션 새 파일, 새 세션은 '최신 1개'만 참조)
wiki/     ← 위키 노트(지식·결정 + [[링크]]) (누적)
   └ INDEX.md  ← 위키 인덱스(노트마다 한 줄 설명, 최신 맨 위, 자동 갱신)
```
> `<작업폴더>` = `claude`를 켠 폴더(cwd)의 **git 루트**다. `lib-project-dir.js` 의 `gitRootOf(cwd)`로 결정 — 하위 폴더에서 켜도 git 루트 한 곳으로 모인다(예: `C:\repo\sub`에서 켜도 `C:\repo\sessions\`). **저장 2훅과 복원 1훅이 모두 같은 `gitRootOf(cwd)`를 쓰므로 항상 같은 곳을 읽고 쓴다.** git repo 밖이면 cwd로 폴백.

## 0-2. 노트 3종 구성
- **이어가기 요약**(summary): `## 한 일 / ## 현재 상태 / ## 다음 할 일` — 작업 이어가기용(짧음)
- **위키 노트**(wiki): 핵심 지식·결정·산출물을 주제별 정리 + `[[링크]]` — 지식 누적용(옵시디언)
- **INDEX.md**: `- [[노트]] — 한 줄 설명` 목록 — 지식 지도

## 1. SessionEnd 훅 — 세션이 "끝날 때"
- 발동: `/exit`·`/quit`·Ctrl+D 등 종료 시. 입력에 `transcript_path`(이번 대화 .jsonl)·`cwd`·`reason`.
- 종료를 막을 수 없음(공식) → "저장" 전용으로 적합.
- 훅은 셸 스크립트라 요약 못 함 → 똑똑한 요약/위키는 백그라운드 `claude -p`(Sonnet)가 담당.
- 연결: `session-save-raw.js`(원본 복사) + `session-to-wiki.js`(detached로 워커 실행, 비차단).
- 저장 위치: 두 훅 모두 `lib-project-dir.js` 의 `gitRootOf(cwd)` 로 git 루트를 구해 그곳 `sessions/`에 저장(0-1 참고). 복원 훅도 동일 기준.

## 2. SessionStart 훅 — 세션이 "시작될 때"
- stdout 출력이 새 세션 맨 앞 컨텍스트로 자동 주입됨(SessionStart 고유).
- 연결: `session-restore.js` → ① summary 최신 1개 ② wiki 최신 노트 본문 ③ INDEX.md 주입.
- `source=clear`면 주입 생략.
- **백필 안전망**: 주입 전, `SessionEnd` 미발화로 저장이 누락된 직전 세션을 자동 복구한다. ① 싼 게이트(`stat`만, 내용 안 읽음)로 "이 git 루트에 새 미저장 세션이 있는지" 확인(정상 종료라 이미 저장됐으면 즉시 통과 → 상시 비용 0). ② 누락 감지 시에만 `~/.claude/projects`의 최근 72h 원본을 스캔해 **raw에 원본 복사(멱등)** + **미요약 최신 1개를 워커로 증류**(증류 결과는 다음 세션부터 주입, 현재 세션엔 복구 알림+원본 경로 출력).

## 3. settings.json 등록
```jsonc
"SessionStart": [ { "hooks": [
  { "type":"command", "command":"node \"c:/Users/<사용자명>/.claude/hooks/session-restore.js\"" }
] } ],
"SessionEnd": [ { "hooks": [
  { "type":"command", "command":"node \"c:/Users/<사용자명>/.claude/hooks/session-save-raw.js\"" },
  { "type":"command", "command":"node \"c:/Users/<사용자명>/.claude/hooks/session-to-wiki.js\"" }
] } ]
```

## 4. 도구 · 종료 키워드
- 자동 재접속: 프로젝트 폴더에서 **`cloop`** (WinPS 프로필 함수 — `claude --dangerously-skip-permissions` 무한 루프).
- 세션 나가기: **`/exit`** (또는 `/quit`).  루프 완전 종료: 세션 종료 후 5초 안에 **`q`**.
- `/마무리` 명령은 자동화로 대체되어 **삭제됨**.

## 5. 구현 메모
- 워커 인증: 잘못된 `ANTHROPIC_API_KEY` 제거 후 OAuth 사용.
- 재귀 방지: 워커가 띄운 `claude -p` 세션은 `CLAUDE_WIKI_CHILD=1` → 그 세션의 훅은 no-op.
- Sonnet 출력 분리: `@@@TITLE@@@` / `@@@HANDOFF@@@` / `@@@WIKI@@@` 줄단위 마커.
- 모델: `claude-sonnet-4-6` (워커에서 변경 가능).
- 품질 자기검증: 마커 부족·빈 출력·타임아웃이면 **1회만 재시도** 후 폴백 + frontmatter `quality: degraded` 기록. 복원 시 degraded 요약이면 경고 한 줄 동봉.
- 요약 retention: `summary/`는 최신 10개(`SUMMARY_KEEP`)만 두고 나머지는 `summary/_archive/`로 이동(삭제 아님).
- INDEX 정합성: 갱신 시 실제 파일 없는 `[[링크]]`(ghost) 자동 제거, orphan(미색인 파일)은 로그만.
- 저장 위치: `gitRootOf(cwd)`(켠 폴더의 git 루트). 저장 2훅·복원 1훅 동일 기준이라 항상 일치. 비-git은 cwd 폴백. (예전 `resolveProjectDir`(전사 최다편집 라우팅)은 복원이 재현 불가해 제거.)
- 백필: `SessionStart`가 `SessionEnd` 미발화 누락분을 복구 — 싼 게이트(`stat`만)로 정상 시 비용 0, 누락 시에만 raw 복사 + 미요약 최신 1개 증류.

## 6. 실사용 사이클
```
1) 프로젝트 폴더에서:  cloop
2) 무거워지면:  /exit            → 원본+요약+위키+INDEX 자동 저장
3) 자동 재접속 → 새 세션이 [요약 + 직전 위키 + INDEX] 읽고 이어감
4) 완전히 끝낼 때:  /exit 후 5초 안에  q
```
