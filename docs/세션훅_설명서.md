# 세션 훅 설명서 — SessionStart · SessionEnd

> Claude Code의 세션 시작/종료 훅과, 여기 구축된 "저장→종료→재접속→복구" 시스템 설명서.
> 작성: 2026-06-07 · 근거: 공식 문서 code.claude.com/docs/en/hooks.md

---

## 0. 한눈에 보는 전체 흐름

```
[컨텍스트 무거워짐]
   │  /마무리          (살아있는 세션이 가벼운 요약 노트 작성 → sessions\raw\ + LATEST.md)
   │  /exit            (세션 종료. Ctrl+D 대체)
   ▼
SessionEnd 훅  →  session-save-raw.js  →  대화 원본(.jsonl)을 <작업폴더>\sessions\raw\ 에 자동 저장
   │
   │  (cloop 래퍼가 5초 뒤 새 세션 자동 재실행 / 끝내려면 q 키)
   ▼
SessionStart 훅  →  session-restore.js  →  LATEST.md를 새 세션 첫머리에 자동 주입
   ▼
[새 세션이 가벼운 요약만 읽고 이어서 작업]
```

핵심 아이디어: **컨텍스트는 항상 가볍게 유지, 기억은 파일로 보존, 새 출발 때 요약만 주입.**
컴팩트(/compact)는 느리고 불편해서 쓰지 않는다.

---

## 1. SessionEnd 훅 — 세션이 "끝날 때" 발동

### 언제 발동되나
세션이 종료될 때. 입력에 종료 사유(`reason`)가 들어온다:

| reason | 상황 |
|---|---|
| `other` | 일반 종료 (`/exit`, `/quit`, Ctrl+D, 크래시 등) ← 보통 이 경우 |
| `clear` | `/clear` |
| `resume` | `--resume` / `--continue` / `/resume` |
| `logout` | `/logout` |
| `prompt_input_exit` | `-p`(print 모드) 처리 종료 |
| `bypass_permissions_disabled` | 권한 모드 해제 |

### 훅이 받는 정보 (stdin JSON)
```json
{
  "session_id": "...",
  "transcript_path": "C:\\...\\.claude\\projects\\...\\<id>.jsonl",
  "cwd": "현재 작업 폴더",
  "hook_event_name": "SessionEnd",
  "reason": "other"
}
```
- `transcript_path` = **이번 세션 대화 전체가 담긴 .jsonl**. 종료 시점엔 끝까지 기록돼 있어 그대로 읽을 수 있다.

### 중요한 성질
- **종료를 막을 수 없다** (공식 문서 명시). 이미 끝나는 중에 끼어들어 작업만 한다. → 그래서 "안전망 저장"에 적합.
- **요약(증류)을 못 한다.** 훅은 셸 스크립트(LLM 아님). raw 보존까지가 한계. 똑똑한 요약은 `/마무리`(살아있는 세션)가 담당.

### 여기 연결된 스크립트: `session-save-raw.js`
- `transcript_path`의 .jsonl을 **`<cwd>\sessions\raw\`** 에 복사 (폴더 없으면 생성).
- 파일명: `<타임스탬프>_<session_id>.jsonl`
- **멱등**: 같은 session_id 파일이 이미 있으면 건너뜀(중복 방지).
- 어떤 reason이든 raw는 보존. 절대 차단 안 함(exit 0).

## 2. SessionStart 훅 — 세션이 "시작될 때" 발동

### 언제 발동되나
세션 시작 시. 시작 종류(`source`)가 구분된다:

| source | 상황 |
|---|---|
| `startup` | 새 세션 (`claude` 그냥 실행) ← 재접속 시 보통 이 경우 |
| `resume` | `--resume` / `--continue` / `/resume` |
| `clear` | `/clear` 직후 |
| `compact` | 컴팩트 직후 |

`source` 별로 matcher를 걸 수 있다(특정 시작에서만 훅 발동).

### 핵심 능력 — 컨텍스트 주입
SessionStart 훅이 **stdout으로 출력한 텍스트는 새 세션 맨 앞 컨텍스트로 자동 주입된다** (SessionStart 고유 특성. 다른 훅은 stdout이 로그로만 남고 모델엔 안 들어감).
- 공식 문서: "훅이 stdout으로 출력한 텍스트는 대화 시작 시 첫 프롬프트 이전에 Claude의 컨텍스트로 자동 추가된다."
- JSON 형식 `{"hookSpecificOutput":{"hookEventName":"SessionStart","additionalContext":"..."}}` 으로도 가능.

### 여기 연결된 스크립트: `session-restore.js`
1. `<cwd>\sessions\LATEST.md` 가 있으면 → 그 내용을 주입 (가벼운 요약 노트).
2. 없고 raw만 있으면 → 최신 raw 경로 포인터 주입("아직 증류 안 됨, 필요하면 읽어라").
3. 둘 다 없으면 → 출력 없음(새 프로젝트).
4. `source=clear`(의도적 초기화)면 → 주입 생략.
- 절대 차단 안 함(exit 0).

## 4. 함께 쓰는 도구

| 도구 | 위치 | 역할 |
|---|---|---|
| `/마무리` 명령 | `~/.claude/commands/마무리.md` | 살아있는 세션이 가벼운 요약 노트를 `sessions\raw\`에 작성 + `LATEST.md` 갱신 (raw 원본은 SessionEnd가 담당) |
| `cloop` 함수 | `~/Documents/WindowsPowerShell/profile.ps1` | 프로젝트 폴더에서 `cloop` → claude를 skip-permissions로 무한 재접속 루프 |

### 종료 키워드 (Ctrl+D / Ctrl+C 대체)
- 세션 나가기: **`/exit`** (또는 `/quit`)  ← Ctrl+D 대체
- cloop 루프 완전 종료: 세션 종료 후 **5초 안에 `q` 키**  ← Ctrl+C 대체

---

## 5. 저장 위치 정리

```
<작업폴더>\sessions\
  ├─ raw\            ← 대화 원본 .jsonl (SessionEnd) + /마무리 요약 .md  (모든 세션 내용)
  └─ LATEST.md       ← 최신 요약 (SessionStart가 읽어 주입하는 포인터)
```

---

## 6. 실사용 사이클

```
1) 프로젝트 폴더에서:  cloop
2) 작업하다 무거워지면:  /마무리   → 요약 저장
3) 나가기:  /exit                   → SessionEnd가 raw 저장
4) 자동으로 새 세션 뜸             → SessionStart가 LATEST.md 주입 → 이어서 작업
5) 완전히 끝낼 때:  /exit 후 5초 안에  q
```
